# Stone, Paper, Scissors

A small command-line game where you play stone, paper, scissors against the
computer. The computer picks randomly, and the game reports whether each round
is a win, loss, or tie.

## Requirements

- Python 3

## How to run

Open a terminal in this folder and run:

```powershell
python stone_paper.py
```

Enter `stone`, `paper`, or `scissors` to play. Enter `q` to quit.
